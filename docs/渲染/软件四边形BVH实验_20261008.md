# VOX 软件四边形 BVH 实验（2026-10-08）

已添加启动参数 `MIKAN_HWRT_SOFTWARE_QUAD_BVH=1`。默认仍为硬件 Ray Query 三角形路径。实验仅支持 VOX，遇到通用模型或奇异实例变换拒绝软件场景输入；RTXDI SDK 在软件模式禁用。此次验收配置是普通 NEE DI1/GI1、NRD+TAA，ReSTIR、DLSS RR/SR、FG 和 DDA 关闭。

## 实现与入口

- `src/Rendering/RayTracing/SoftwareQuadBvh.h`：场景输入变化时构建世界空间二叉 BVH，三个轴的 centroid sweep SAH，叶子最多4面（深度上限48时例外）。32字节节点、16字节面记录、96字节实例记录。面记录包含原有4字节四边形、平面/方向及命中标识，避免每次候选测试二分查平面表。
- `engine/shaders/glsl/vox_rt_software_quad.glsl`：64项栈，近处优先遍历，方向倒数复用、实例局部射线缓存。直接求矩形平面交点并检查二维范围，阴影首命中提前返回。局部射线不归一化，保留非均匀缩放下世界空间 t。
- `vox_rt_realtime.comp` 专门化常量14选择软件路径，SSBO绑定41。主命中、镜面续射、普通GI及NEE/太阳/天空阴影使用软件查询。
- 为复用调色板、降噪命中记录和发光体MIS映射，矩形命中编码为原两半面的 primitive ID/bary；这里没有进行两次三角形求交。
- `RayTracingViewport.cpp` 使用现有不可变 SceneInputs 缓存/上传 BVH，`RayTracingScene` 传递 castShadow 对应的射线掩码。

**边界：这只是软件求交实验，现有管线初始化仍要求 Ray Query 能力，仍准备硬件 BLAS/TLAS；尚未改为无RT设备可启动的独立后端。软件 ReSTIR GI/RR 未验收，部分其他模式仍有硬件查询，不应据本次NEE结果宣称所有模式已软件化。** 当前BVH按实例展开世界空间四边形，尚未实现共享局部BLAS+实例TLAS。

OpenGL参考检查入口是 `mikan engine opengl/assets/shaders/postprocess/raytrace.fragment`、`pass1.fragment`；这两个文件中找到的是软件三角形BVH遍历。此次直接矩形求交利用当前Vulkan引擎的规则VOX四边形数据实现。

## 780M 实测

同一游戏视角，rom + haruto，共681个四边形（硬件对应1362个三角形）；软件BVH471节点、深度13，缓冲26176字节。内部960×540，输出1920×1040。截图第120帧，两个实例各123帧正常退出；目视几何/材质/阴影无明显差异。PNG平均通道绝对差0.00690/255，最大4/255，不能作为线性HDR方差或无偏性证明。

GPU timestamp独立计时，不带截图；硬件/软件交替3轮，每轮720帧、预热120帧，每路径1800个有效样本。用户要求不继续追加测试，以下使用已经完成的记录。

| GPU阶段 | 硬件三角形 ms | 软件四边形 ms | 软件/硬件 |
|---|---:|---:|---:|
| 主命中 | 1.309 | 1.834 | 1.40 |
| DI/GI/Specular光照 | 4.855 | 19.616 | 4.04 |
| RT视口总计 | 10.544 | 25.975 | 2.46 |
| GPU整帧 | 11.668 | 27.074 | 2.32 |

硬件整帧各轮11.266/11.955/11.782ms；软件26.893/26.510/27.818ms。父子scope嵌套，不能求和；计时不含进程启动，非屏幕显示FPS。未锁GPU频率，聚合日志不提供p95/置信区间。当前实测软件路径仍较慢，差距主要在光照续射阶段；没有GPU硬件计数器证据，不将寄存器/分歧等推测当作已确认原因。

第一版反复解码平面表/变换局部射线，软件光照约36.98ms；消除重复工作后的最终版本为上述19.616ms。这里只报告最终版对比。

```powershell
$env:MIKAN_GPU_PREFERENCE='780M'
$env:MIKAN_HWRT_SOFTWARE_QUAD_BVH='1' # '0'为硬件基线
$env:MIKAN_HWRT_VOXEL_DDA='0'
$env:MIKAN_HWRT_UNBIASED_RESTIR='0'
$env:MIKAN_HWRT_RTXDI='0'
$env:MIKAN_HWRT_DLSS_RR='0'
$env:MIKAN_HWRT_DLSS_SR='0'
$env:MIKAN_DLSS_FG='0'
$env:MIKAN_HWRT_NEE_DI_SPP='1'
$env:MIKAN_GPU_PROFILE='1'
$env:MIKAN_GPU_PROFILE_WARMUP='120'
& './out/build/x64-Release/MikanEngine.exe' --project '<项目目录>' --scene '<场景绝对路径>' --headless --no-editor --frames 720 --fixed-dt 0.016666667
```
