# Jolt 立方体堆叠物理原型

这是一个直接使用引擎 Jolt 3D 物理系统的演示场景：运行时创建大量动态立方体，让它们从空中下落并在拉伸立方体地面上堆叠。

## 重点

- 864 个动态 `BoxShape`，由 `PhysicsSystem` 统一驱动位置、旋转、重力和碰撞响应；
- 所有方块复用引擎基础 cube 模型，可由渲染器合批/实例化，避免为每个方块复制网格资源；
- 方块使用 `ShapeType::OBB`，旋转后的碰撞盒仍与模型方向一致；调试包围盒线框默认关闭，避免干扰堆叠展示；
- 地面不是无限平面，而是一个尺寸为 `20 x 1 x 20` 的拉伸 cube，顶部位于 `y = 0`；
- cube 模型局部包围盒按 `[-1, 1]` 处理：刚体基准尺寸固定为 `[2, 2, 2]`，实际世界尺寸由 Transform 缩放精确得到；
- `autoFitToModel=false`，避免重复套用模型 AABB 造成碰撞盒膨胀；
- 停止播放时保留方块并重建刚体，恢复到第一帧，不绑定任何键盘输入。

## 面试可讲

场景资源只负责相机、光源和地面；方块由玩法插件在 `OnSceneLoaded` 动态创建。每个实体添加 `Transform + Mesh + Render + Material + RigidBody`，Jolt 物理系统通过 ECS 签名自动接管实体。这样可以同时展示 ECS 动态实体、Jolt 刚体生命周期、精确 OBB 碰撞以及同模型批处理。
