# CPU 布料弹簧网格原型

这是一个用于面试展示的 CPU 布料实验项目。模拟器使用规则质量点网格和结构/剪切/弯曲弹簧，并在半隐式 Euler 动力学之后执行位置约束投影。

当前场景同时展示两种布料：

- 左侧 `Hanging Cloth` 改为初始水平平铺的 28×20 质量点网格，左侧一整条边固定，另一侧自由下落到地面；
- 右侧 `Falling Wrap Cloth` 使用 28×20 个质量点，物理范围为 4.0×4.0 的正方形，初始位于球体正上方，中心与球心 X/Z 对齐，自由下落并包裹 `Wrap Sphere`；
- 两块布料都显示表面和弹簧拓扑，青色/紫色/橙色线分别表示结构、剪切和弯曲弹簧；
- 球体与布料共用透明调试表面管线，方便观察穿透、接触和包裹状态；
- `CPU Cloth` 根实体的 Transform 由场景树控制，旋转会同步到模拟局部坐标，不占用键盘输入；
- 相机采用轻微俯视角，能同时看到左侧平铺布料和右侧球体包裹过程；
- 未播放时保留重置后的第一帧，播放后才推进 CPU 模拟；停止播放后会恢复场景快照并重新初始化游戏模块，粒子/布料不会消失。

此前出现的“自己抖动”主要来自高刚度弹簧配合半隐式 Euler 时积累的伸缩误差，以及持续风场不断激发固有模态。当前版本降低弹簧刚度、提高速度阻尼，默认关闭风场，并加入 5 次弹簧长度投影和速度重建，避免布料在静止状态持续 buzz。

这是一个 CPU 原型，后续可以加入 XPBD compliance、更多碰撞体、布料自碰撞、可调风压和 GPU Compute 版本。
