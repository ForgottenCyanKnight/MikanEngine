# Quaternius Universal Animation Libraries

Downloaded for MikanEngine animation state-machine prototyping.

## Included packs

- `Universal Animation Library 2 [Standard]`: 43 clips, 55-bone humanoid rig, GLB/FBX/Blend.
- `Animation Library[Standard]`: 46 clips, humanoid rig, GLB/FBX.
- `Female Mannequin`: rigged GLB/FBX/Blend example from the second pack.

The current engine successfully imports the UAL2 GLB as a skinned model with 43 animation clips.
The library skeleton is not the same as CesiumMan's 19-bone skeleton, so direct playback on
CesiumMan requires a later retargeting step.
